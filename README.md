# 🍎 Chasseur de Fruits Arcade (Pygame)

Un jeu de plateforme et de collecte dynamique inspiré des classiques rétro, développé en **Python** avec **Pygame**.

---

## 📸 Fonctionnalités

- 🏃 **Plateforme fluide :** Cours et saute par-dessus les obstacles pour explorer le niveau.
- 🍓 **Collecte de fruits :** Attrape un maximum de fruits pour faire grimper ton score (+15 points par fruit)[cite: 2].
- 🕷️ **Ennemis mobiles :** Esquive les insectes patrouillant sur les plateformes.
- ❤️ **Système de vies :** 3 vies pour établir le meilleur score de la session[cite: 2].

---
